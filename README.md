# TikTok Music Overlay — расширение для Chrome

Добавляет вкладку «Музыка» на странице профиля TikTok и оверлей-плеер с реальным аудио.
Источник музыки — TikTok Studio: расширение перехватывает аудио-запросы, которые делает Studio,
и сохраняет найденные треки. На профиле они появляются в плеере.

## Установка (что и где активировать)

1. Открой Chrome и перейди на страницу:
   `chrome://extensions/`
2. Включи переключатель **«Режим разработчика»** (Developer mode) — справа вверху.
3. Нажми **«Загрузить распакованное расширение»** (Load unpacked).
4. Укажи папку:
   `D:\\code\\ICE\\Pytho\\tiktok-music-ext`
5. Расширение появится в списке. Убедись, что оно **включено** (тумблер синий).

## Где что активировать внутри TikTok

### 1. Страница TikTok Studio (источник музыки)
- Открой: `https://www.tiktok.com/tiktokstudio/upload?from=webapp&tab=video`
- **Важно:** ты должен быть залогинен в TikTok (иначе Studio редиректит на страницу входа).
- Когда на странице Studio откроется/заиграет музыка — расширение само поймает аудио-URL
  (через `webRequest` в background + скан страницы в `content-studio.js`).
- Ничего нажимать не нужно — сбор идёт автоматически.

### 2. Страница профиля (где появляется плеер)
- Открой: `https://www.tiktok.com/@ygandosheni`
- В ряду вкладок (**Видео / Репосты / Избранное / Понравившееся**) появится новая кнопка
  **🎵 Музыка**.
- Нажми её — откроется оверлей-плеер (справа снизу):
  - список сохранённых треков,
  - кнопка Play/Pause и системный аудиоплеер,
  - кнопки «Очистить» и «Обновить».

## Порядок работы (чтобы всё сработало)

1. Залогинься в TikTok в том же Chrome.
2. Сначала зайди на страницу **TikTok Studio** — там расширение соберёт треки.
3. Потом открой **профиль** `@ygandosheni` — нажми кнопку **🎵 Музыка** — треки уже там.

## Если треков нет

- Открой `chrome://extensions/` → карточка расширения → **«Ошибки»** (Errors).
- Проверь, что ты именно **залогинен** — без логина Studio не отдаёт музыку.
- Проверь вкладку **Console** на странице Studio: могут быть ошибки CSP/фетча.
- Обнови вкладку профиля — кнопка добавляется с задержкой до 20 секунд (SPA TikTok грузится не сразу).

## Структура файлов

- `manifest.json`      — описание расширения (MV3)
- `background.js`      — service worker, перехват аудио-запросов
- `content-studio.js`  — сбор аудио на странице TikTok Studio
- `content-profile.js` — кнопка «Музыка» + оверлей-плеер на профиле
- `overlay.css`        — стили оверлея

## Что можно доработать

- Если TikTok отдаёт музыку не прямым mp3, а через MSE/blob — аудио не перехватится как URL.
  Тогда нужно доработать: сохранять сам blob или брать ссылку из JSON-ответа API (`/api/music/...`).
  Скажи — посмотрю конкретные запросы на твоей странице Studio и допишу парсинг.
- Можно добавить автора/название из метаданных API (сейчас берётся имя файла).
